## 修复

1. 状态提示要求每条证据是连续原文，禁止把分隔的岗位、状态和日期拼接起来。岗位身份对应只忽略明确的末尾志愿徽标；优先精确名称，别名必须唯一，并限定同账号、同公司、同申请页。歧义不自动合并。原始证据、手动名称和历史不迁移重写。
2. 匹配检查实际简历中引用对应关键词的上下文，以及完整岗位字段里的熟练要求。换到岗位方向维度或截短成技能词不能绕过限定。章节标题和其他技能的限定词分别处理。
3. 模型返回的 `/mnt/user-data/uploads/<文件名>` 可对应本轮已经读取的同名上传文件；不接受任意路径取 basename、不读取新文件，也不接受未读取文件、子目录或 `..`。
4. 匹配证据标记升级为 `match_contract_version=2`。实时、历史、打印和下载统一要求当前版本；旧报告提示重新生成。
